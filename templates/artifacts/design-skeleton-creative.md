# 视频骨架设计（创作模式）：{主题}

> 创作模式：用户给定主题或文章，AI 自由创作内容、时间轴和画面。
>
> ⚠️ **关键**：本文件生成后，必须执行 `scripts/generate-skeleton.js` 自动生成 `skeleton.json`，严禁手动编写 JSON。

---

## 项目配置（JSON）

```json
{
  "name": "",
  "description": "",
  "viewport": {"width": 780, "height": 585}
}
```

**字段说明**：

| 字段 | 必填 | 说明 |
|------|------|------|
| name | ✅ | 视频名称 |
| description | ❌ | 视频描述 |
| theme | ❌ 可选 | 背景主题 `white` / `black`，省略时用默认值 |
| duration | ❌ 可选 | 总时长（秒），省略时用默认值 |
| viewport | ✅ | 视口尺寸，默认 `{"width":780,"height":585}` |
| bgm | ❌ 可选 | BGM 风格，省略时用默认值 |

**BGM 匹配规则**：

| 视频主题/关键词 | 选用 BGM |
|---|---|
| AI / 编程 / 算法 / 数据 / 科技 | `tech-pulse` |
| 咖啡 / 餐饮 / 生活方式 / 温馨 | `warm-cafe` |
| 创业 / 成长 / 励志 / 教育 | `uplifting` |
| 企业 / B2B / 演示 / 商务 | `corporate` |
| 教程 / 科普 / Vlog / 轻松 | `light-pop` |
| 旅行 / 纪录片 / 大场面 | `cinematic` |
| 不明确 | `corporate`（默认） |

---

## 区域列表

> 每个区域一行，脚本自动提取生成 `regions` 数组。
> **必填列**：名称、时长（秒）、内容描述。其余列可选，脚本不读。

| 区域 ID | 区域名称 | 时长(秒) | 内容描述 |
|------|---------|----------|----------|
| P1 | 主题引入 | 3 | AI时代如何学习 |
| P2 | 核心要点 | 5 | 三个核心方法 |
| ... | ... | ... |

0.0s  - 3.0s    P1 Hook       [高]
3.0s  - 8.0s    P2 Point      [中]
...
```

高 → 中 → 高 → 中
```

## 自检清单

脚本自动校验：总时长之和等于目标时长。

AI 写完后自查：
- 情绪曲线有起伏
- BGM 风格与主题匹配
