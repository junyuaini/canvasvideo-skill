# 场景问答

> 以下是常见问题的判断标准，帮助 AI 在具体情境下做出正确决策。

---

## Q1：state.json 路径在哪里？generate-skeleton 报"state.voice 为空"是什么问题？

**先确认路径**：`state.json` 固定在 `{Agent工作目录}/canvasvideo-workdir/.canvasvideo/project-state.json`，即 `--cwd` 传入的目录 + `canvasvideo-workdir/.canvasvideo/`。

**不要被 init-project 的输出混淆**：脚本打印的"工作目录"是 `{workdirRoot}/{skillProjectId}/`，是放项目文件的地方；而 state.json 实际写在 `workdirRoot/.canvasvideo/` 下，两者是不同的。

**"state.voice 为空"的常见原因**：
- 步骤 1.5 还没跑，state.voice 仍为 null → 先执行 `prepare-voice.js`
- state.json 放错位置（放到了 `{skillProjectId}/.canvasvideo/` 或 `{Agent工作目录}/.canvasvideo/`）
- 口播模式跳过步骤 1.5 直接手动写 state → 字段名必须是 `audioPath` 和 `srtPath`

---

## Q2：口播模式中，state.voice 的字段名是什么？

**必须是 `audioPath` 和 `srtPath`**，不要用 `path`。

正确的 state.voice 结构：
```json
"voice": {
  "audioPath": "./assets/voice.mp3",
  "srtPath": "./assets/subtitles/subtitle.srt",
  "duration": 83.4
}
```

注意：这里 `audioPath`（不是 `path`）是脚本之间的约定，与 `project.json` 里的 `audio.path` 是不同层级的东西。
